## ⚡ Instant 1-Command Installation

### 1. In any existing or new project workspace:
Clone the repository and run the installer:

```powershell
# Windows PowerShell
git clone https://github.com/Kuldeep8447/kuldeep-antigravity-skills.git
cd kuldeep-antigravity-skills
powershell -ExecutionPolicy Bypass -File install.ps1
```

```bash
# Linux / macOS
git clone https://github.com/Kuldeep8447/kuldeep-antigravity-skills.git
cd kuldeep-antigravity-skills
bash install.sh
```

### 2. Global Installation (Accessible across all IDE projects):
```powershell
# Windows PowerShell
powershell -ExecutionPolicy Bypass -File install.ps1 -Global
```

```bash
# Linux / macOS
bash install.sh --global
```
